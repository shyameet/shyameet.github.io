Connect this browser

This editor talks straight to GitHub from your phone. The token is kept only in this browser's local storage — never in the site's code, and never sent anywhere except api.github.com.

How to get a token (a minute)
  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → pick this repo
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Set an expiry you are happy with, generate, and paste it below.
